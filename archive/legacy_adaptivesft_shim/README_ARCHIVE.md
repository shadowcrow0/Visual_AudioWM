# legacy_adaptivesft_shim

An early copy of the salience-calibration package (9b73c21) that lived at the root of this repo. Nothing imports it: the experiment uses the real `adaptiveSFT` repository next door (`adaptive_vawm_EN.load_full_package`). Left at the root it shadowed that package whenever this folder came first on `sys.path`. Frozen here 2026-11-24.
