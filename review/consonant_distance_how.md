Output: `review/data/consonant_distance_all_pairs.csv` (120 pairs × every metric) and

## 1. The five metrics

```
            matrix N (spoken i, heard j)
                 |
     +-----------+-----------+-----------------+
     v           v           v                 v
  feature     r_ab rate    s_ab = (n_ab+n_ba)  Luce choice model
  table XIX   −ln r        /(n_aa+n_bb)      P(j|i)=b_j·η_ij/Σ_k b_k·η_ik
     |           |           |                 |
  hamming     confusion    classical MDS      d = −ln η_ij
  weighted                 (Torgerson)
```

| metric | formula | status |
|---|---|---|
| `hamming` | number of differing features (0–5; place counts 1 whenever it differs) | descriptive baseline |
| `weighted` | `Σ_f T_rel(f)·[f(a)≠f(b)]`, `T_rel = I(spoken; heard)/H(spoken)`, each feature collapsing the 16×16 matrix to 2×2 (place 3×3) | Miller & Nicely's own "five channels" view |
| `confusion` | `r_ab=(n_ab+n_ba)/(N_a+N_b)`, `d=−ln(r+ε)`, `ε=0.5/(N_a+N_b)` (half-count floor; an unobserved confusion → ≈6.9), averaged over −12/−6/0 dB | descriptive |
| `mds` | pool −12/−6/0 dB counts → `s_ab` → `−ln s` → classical MDS, Euclidean distance in the first 3 dims | Shepard's geometric picture |
| `luce` | per SNR, maximum-likelihood fit of 120 η and 15 biases b (+0.5 on every cell; gradient ascent started from the closed form `η≈√(p_ij p_ji/(p_ii p_jj))`), `d=−ln η`, averaged over −12/−6/0 dB | measurement model of the perceptual decision |

Why only −12/−6/0 dB: at −18 dB the table is nearly uniform (the 16×16 channel carries 0.06 bit, every pair looks equally close); at +6/+12 dB 175 and 199 of the 240 off-diagonal cells are empty, so every distance hits the ε ceiling.

## 3. Spearman correlations (120 pairs; `current` = the 71 pairs present in CONFUSION_DATA)

```
            hamming weighted  conf   mds3   luce  current
  hamming     1.00   0.89    0.54   0.57   0.57   0.49
  weighted    0.89   1.00    0.71   0.74   0.73   0.75
  confusion   0.54   0.71    1.00   0.94   0.96   0.87
  mds3        0.57   0.74    0.94   1.00   0.94   0.84
  luce        0.57   0.73    0.96   0.94   1.00   0.84
```

The three matrix-derived metrics (confusion / mds / luce) agree at ≥ 0.94; the two feature-derived ones agree with them only at 0.5–0.75. The disagreement is concentrated in the **voicing-only pairs**: p-b, t-d, k-g, ʃ-ʒ rank 37th under `weighted` (0.81 of 2.78) but 81st–108th under `luce` (4.5–5.0 of 5.44), because voicing almost never fails in noise.

MDS: the 3-dim solution has r(fitted, input) = 0.95 and stress-1 = 0.14; dimension 1 correlates 0.98 with voicing, dimension 2 is a blend of nasality / duration / place (0.63 / 0.74 / 0.58), and no single dimension isolates nasality.

Luce model: per-SNR G²(df = 105) between 95 and 146; the ML and closed-form −ln η correlate ≥ 0.99; fitted biases b span 0.5–2.3, i.e. the raw confusion rates do contain response bias.

## 4. Which metric is closest to cognitive theory

- **`luce`** (the similarity-choice model, Luce 1963 / Shepard 1957) is a **measurement model** of the perceptual decision: it separates similarity η from response bias b. Shepard's (1987) universal law `similarity = exp(−distance)` makes −ln η a psychological distance, and Nosofsky's (1986) GCM uses the same η for categorisation and recognition memory. It is the only one of the five with a path from the confusion matrix to a memory model.
- `mds` is Shepard's (1972) geometric picture of the same thing (0.94 with luce), but it needs a choice of dimensionality and the Torgerson solution is not maximum likelihood.
- `weighted` is Miller & Nicely's own "five independent channels" view: theoretically motivated, but it compresses the 120 pairs to at most 27 values.
- `hamming` and `confusion` are descriptive only; `confusion` correlates 0.96 with luce and is the bias-uncorrected approximation to it.

## 5. Recommendation: `luce` (mean over −12/−6/0 dB) as the sound axis

Reasons: clearest theoretical status, continuous (120 distinct values), every consonant has 15 foils spanning 0.3–5.4, and it correlates 0.84 with the current axis (a correction, not a reversal).

Binning (cut points chosen to maximise the minimum partners per consonant per level):

```
  4 levels  edges 0.29 | 3.04 | 4.09 | 4.68 | 5.44      31/31/27/31 pairs   every consonant ≥ 1 per level  ✔
  5 levels  edges 0.29 | 2.28 | 3.53 | 4.29 | 4.84 | 5.44  24/23/23/26/24 pairs
            gaps: t has no partner in level 3 (3.5–4.3); z has none in level 5 (> 4.84)
```

Both 5-level gaps are near misses (t's nearest are ʃ 3.0 / ð 4.3; z's farthest are f, k at 4.8), and `foil_nearest` already snaps x to the nearest available foil and returns the actual distance, so 5 levels are usable; merge levels 4 and 5 if a strict guarantee is wanted. For comparison, `weighted` at 5 levels (0.29|0.73|0.88|1.14|1.53|2.78) and `confusion` at 5 levels (1.34|3.23|4.70|5.70|6.11|6.53) give every consonant ≥ 1 partner per level; at 6 levels all three metrics have gaps.

## 6. Limitations

1. **Noise ≠ memory.** These distances measure identification in noise. Whether the same structure holds in short-term memory has not been tested numerically: Wickelgren (1966) showed consonants are stored as semi-independently forgotten feature bundles, Klatt's (1968) re-analysis found voicing among the features retained in memory and place not, and Conrad (1964) found listening and recall confusions correlated (letters only). No ranking of feature loss in memory exists (see `millerNicely1955_噪音混淆_逐SNR.md` §7–8). `luce` puts the voicing-only pairs at the far end; treat that as a hypothesis to check with the perception test and the WM data, and if voicing itself is the question, `weighted` or direct calibration is the alternative — switching is one constant.
2. The listeners were native English speakers; η for non-native listeners will differ.
3. Three-valued place is reduced to same/different: f-θ and p-k both count as one place step.
4. Only the CV /ɑ/ context and one small talker group; `stimuli/` uses 12 talkers' /…3/ files.
5. η comes from an ML fit on +0.5-smoothed cells; at +6/+12 dB η is almost entirely the smoothing constant and should not be used.

## 7. Plugging into `adaptive_vawm_EN.py`

```python
from consonant_distance import foil_nearest, CONSONANTS
SOUND_METRIC = "luce"
LEVELS_AUDIO = [0.6, 1.5, 2.5, 3.5, 4.3, 5.0]   # replaces [-2.6 … -0.3]; six sampling points on the luce scale

# to keep alpha on the previous 0.04–2.4 scale, optionally add AUDIO_SCALE = 0.5 (x*0.5 into the model, /0.5 out)

# make_audio_trial:
#   foil, count = foil_for(confusion, target_sound, x); x_actual = audio_x(count)
# becomes
    foil, x_actual = foil_nearest(target_sound, x, SOUND_METRIC)
# sounds = sorted(confusion) -> sounds = CONSONANTS; store x_actual in the audio*_count columns (or rename to audio*_dist)
# load_confusion / audio_x / count_from_x / foil_for are then only used by the tests and can stay.
```

The calibrated H/L then are luce distances directly, and every consonant has 15 candidate foils instead of 6.
