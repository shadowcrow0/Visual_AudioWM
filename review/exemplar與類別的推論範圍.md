# 「類化到類別而非 exemplar」是在說什麼

**2026-08-12** · 這份是概念說明,不是文獻回顧。
起因:研究者說「實驗室操控優先、生態效度非優先」,我回應說這讓
「單一 token」那條路的主要顧慮鬆開了。這份解釋那句話的內容與**它的界線**。

---

## 一、具體的情境

聽覺維度是 /b/–/p/。你有兩個選擇:

**選項 A —— 每個類別一個錄音**
```
/bi/  →  bi_01.wav   (每個試次都播這一個)
/pi/  →  pi_01.wav   (每個試次都播這一個)
```

**選項 B —— 每個類別多個錄音**(Silbert 2012 用 4 個)
```
/bi/  →  bi_01.wav, bi_02.wav, bi_03.wav, bi_04.wav   (每試次隨機抽一個)
/pi/  →  pi_01.wav, pi_02.wav, pi_03.wav, pi_04.wav
```

**這不只是「多錄幾個比較保險」的差別。兩者讓你有資格說的話不一樣。**

---

## 二、兩個詞的意思

**exemplar(範例)** = 一個**具體的**刺激。`bi_01.wav` 這個檔案本身。
它有這位語者這一次發音的特定 VOT、特定基頻、特定嗓音品質、特定的錄音房間殘響。

**category(類別)** = 那個**抽象的**東西。「英語的 /b/」,不特指任何一次發音。

用選項 A,你的資料是關於**那兩個檔案**的。
用選項 B,你的資料是關於**類別**的 —— 因為個別錄音的怪癖被平均掉了。

---

## 三、你有資格說的話不一樣

假設實驗做完,發現顏色維度會影響聽覺維度的知覺可分離性。

**選項 A 支持的說法**:
> 在本實驗使用的這組刺激上,顏色影響了對 `bi_01.wav` 與 `pi_01.wav` 的辨識。

**選項 B 支持的說法**:
> 顏色影響了對 /b/–/p/ voicing 對比的知覺。

第二句才是你真正想講的話。**選項 A 講第二句就是超出資料範圍的推論。**

### 為什麼不能直接跳過去

因為那個效果可能來自那個錄音的某個特質,而不是來自 voicing 這個類別。
舉例(以下是說明用的假想,不是實測):
- 如果 `pi_01.wav` 剛好錄得比較大聲,顏色的效果可能是在跟「音量」互動而不是「voicing」
- 如果那位語者的 /p/ 剛好送氣特別長,結果可能無法推到送氣較短的語者
- 如果錄音有一點背景嗡聲,那個嗡聲可能才是被顏色影響的東西

**用一個 exemplar,你分不出「這是類別的性質」還是「這是這個檔案的性質」。**

---

## 四、統計上這叫什麼

這是心理語言學的老問題:**stimulus-as-fixed-effect fallacy**(刺激當固定效果的謬誤)。

[[clark1973]] 是這個批評的經典來源:
> Clark, H. H. (1973). The language-as-fixed-effect fallacy: A critique of language
> statistics in psychological research. *Journal of Verbal Learning and Verbal Behavior*,
> 12(4), 335–359. doi 10.1016/s0022-5371(73)80014-3
> (⚠️ 書目經 Crossref 核實,**全文未讀**)

核心論點:如果你想把結論推廣到「語言材料」這個母體,那**刺激也是一個隨機因子**,
不能當成固定的。只用少數幾個刺激卻宣稱結論適用於整個類別,會高估統計顯著性。

**對應到 AVWM**:
- 選項 A = 把刺激當**固定效果** → 結論的範圍就是那兩個檔案
- 選項 B = 把刺激當**隨機因子**(至少部分) → 才有資格談類別

⚠️ 但要注意:**4 個 token 也不多。** Clark 的論證不是「有多個就好」,
而是「刺激的變異要進到誤差項裡」。4 個 token 給的類化力道有限。
後續文獻對怎麼做才對有爭論(例如 Raaijmakers, Schrijnemakers & Gremmen, 1999,
*J. Memory and Language* 41(3), 416–426,doi 10.1006/jmla.1999.2650 ——
書目經 Crossref 核實,未讀全文)。

## 五、為什麼「生態效度非優先」會鬆開這個顧慮

研究者的優先順序是**實驗室操控 > 生態效度**,想知道的是「最底層的知覺現況」。

在這個前提下:

**被降權的**:
- 「結論能不能推到真實世界的語音」—— 明確不是目標
- 「結論能不能推到其他語者」—— 不是目標
- 「結論能不能推到 /b/–/p/ 這個類別的所有實例」—— 弱化成次要

**被升權的**:
- **β 的純度**。GRT 估的是知覺分布的變異數。用多個 token,那些 token 之間的
  聲學差異會**加進**估到的變異裡:
  $$\beta_{\text{估到的}}^2 = \beta_{\text{知覺雜訊}}^2 + \sigma_{\text{token 變異}}^2$$
  用單一 token,$\sigma_{\text{token}} = 0$,β 才是純知覺雜訊。

所以在「要乾淨的參數」這個目標下,**多 token 的好處(類化)被降權,壞處(污染 β)
被升權** —— 這就是我說「主要顧慮鬆開了」的意思。

---

## 六、⚠️ 但它沒有鬆開到你以為的程度

**「不追求生態效度」不等於「可以用 exemplar 資料講類別結論」。**
這兩件事常被混淆,分清楚:

| | 意思 | 「生態效度非優先」有沒有解除 |
|---|---|---|
| **生態效度** | 結論能不能推到實驗室外的真實情境 | ✅ 解除 |
| **對類別的推論** | 結論能不能推到「/b/–/p/」而非「這兩個檔案」 | ❌ **沒有解除** |

第二項是**邏輯上的推論範圍問題**,不是生態效度問題。就算你完全不在乎真實世界,
只要你在論文裡寫「/b/ 和 /p/ 在……」,你就是在做類別宣稱,而你的資料只支持
exemplar 宣稱。

**實務上的處理方式**(三選一,都誠實):
1. **限縮宣稱** —— 寫成「在本實驗的刺激上」,不寫成「/b/–/p/ 的知覺」。
   代價:論文的貢獻變小,但沒有超出資料。
2. **加一個小規模的類化檢查** —— 主實驗用單一 token 拿乾淨的 β,
   另外用少量試次跑 2–3 個額外 token,確認效果方向一致。成本低,能擋審稿意見。
3. **接受多 token 並在分析裡分離它** —— 把 token 當隨機因子建模,
   讓 token 變異進到誤差項而不是 β。這在 hierarchical Bayesian GRT 裡原則上做得到,
   但實作複雜度高很多。(⚠️ 這一項是我的推論,不是我讀到的做法 ——
   正在跑的 subagent 有被指派去查 GRT 文獻怎麼處理刺激變異。)

---

## 七、一句話總結

「類化到類別而非 exemplar」的意思是:
**多個 token 買到的是「講類別的資格」,代價是 β 被 token 變異污染。**

你把生態效度降權之後,那個「資格」的價值變小、污染的代價變大 —— 所以單一 token
變成合理的選項。**但「講類別的資格」不會因為你不在乎生態效度就自動獲得**,
它取決於你最後論文裡怎麼寫。
