# SNR pilot（2026-11-18）：yyc1116，純知覺子音測驗，0 / +6 / +12 dB

資料：`data/yyc1116_sound_perception_dprime_snr{0,6,12}.csv`（各 108 試：72 不同 + 36 相同，d′ 軸，語音形噪音，兩個音節各自的種子）。
分析腳本在 session scratchpad（`snr_pilot.py`、`snr_pairs.py`）；圖在 `review/figures/fig19–21`。
聽者：yyc（非英語母語；11-03、11-10 的受試者同一人）。

## 結果

| SNR | 無反應 | 誤報（相同試） | 命中 0.4 / 0.9 / 1.5 / 2.3 / 3.3 / 4.5 | 50% 點 | 90% 點 | RT 中位數 |
|---|---|---|---|---|---|---|
| 0 dB | 4 | .47（前半 .44、後半 .50） | .50 .73 .50 .82 .75 .90 | d′ 0.2 | 5.5 | 1.8 s |
| +6 dB | 0 | .28（前半 .35、後半 .21） | .83 1.00 .50 .83 .83 .75 | 0.4 | 4.6 | 1.4 s |
| +12 dB | 3 | .23（前半 .21、後半 .25） | .75 .92 .58 .92 .91 1.00 | 0.6 | 2.4 | 1.6 s |

50% / 90% 點來自對「實際 d′」的 logistic 擬合（相同試放在 d′ = 0）。

## 讀法

1. **這把尺對這位聽者沒有排序力，跟噪音無關**：75 個對子的命中率對 d′ 的相關 r = .07（三個 SNR 合併）。11-03 乾淨條件也是 r ≈ .06。特徵數反而排得出來（差 1 / 2 / 3 / 4 個特徵：.70 / .79 / .92 / .94）。
2. **掉的是特定的對子，不是特定的 d′**：m–n / n–m（d′ 1.59）三個 SNR 合計 6/16（n–m 3/11、m–n 3/5；原文誤寫 2/12，2026-11-24 更正）；ð–g 1/6；θ–k 1/4；d–b 2/4；f–v、k–ʃ、v–f 各 .5。1.5 那級三個 SNR 都是 .50–.58，因為它幾乎都是 m–n 和 ð–g。
3. **噪音主要加的是誤報**：.47 → .28 → .23。+6 dB 的誤報從前半 .35 掉到後半 .21、命中 .73 升到 .86，像是在學「忽略噪音紋路」；0 dB 沒有這個學習（.44 → .50）。
4. **說話者效應大**：T03 .57、T09 .55 vs T01 .92、T12 .90（合併三個 SNR）。
5. 即使 +12 dB，斜率（1.19 / d′）也遠比乾淨時平；0 dB 的 90% 點在尺外（5.5）。

## 結論

- 這位聽者的資料**不能用來選 SNR**：問題不在噪音量，在尺本身對非母語者無效（Cutler et al. 2004 的方向）。選 SNR 要用目標族群的聽者（英語母語者）重跑同樣三個條件。
- 如果正式受試者是非母語者，要換的是尺，不是 SNR：用非母語者的混淆矩陣重算（Cutler 2004 有荷語聽者的英語子音矩陣，但荷語 ≠ 華語），或改用「特徵數」當軸（這份資料它排得出來）。
- 程式面沒有問題：三個檔的 `snd_snr_db`、`snd_seed_1/2` 都在，無反應 0–4，RT 合理。
- 說明文字可以加一句「兩個音節的背景噪音每次都不一樣，只聽子音」；+6 dB 後半誤報下降顯示這是可學的。
