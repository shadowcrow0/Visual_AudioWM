資料：`data/WEB01_snr_pilot_2026-11-24_11h46.csv`（Pavlovia 原始檔；原檔的 participant 欄是佔位字 `test`，存入時改成 `WEB01`）、
`data/WEB01_sound_perception_dprime_snr{0,6,12}.csv/.json`（`online/pavlovia_to_perception_csv.py` 轉出）。
圖：`review/figures/fig31_WEB01_conversion_curve.png`、`fig32_quartiles_WEB01_vs_yyc1116.png`。

**這位聽者的母語沒有記錄**（線上版沒有問）。下面的解讀都不依賴他是不是英語母語者；要用這份資料談「不論母語」之前必須先補這一項。

## 1. 這一場

- 324 題（108 題 × 3 個 SNR），全部有反應，耳機檢查 6/6，全程 19.7 分鐘，RT 中位數 0.90 s。
- SNR 順序固定 0 → +6 → +12 dB，三個 block 用的是同一組 108 題（同樣的對子與說話者）。**SNR 與練習、與題目重複完全混在一起**，
  所以「命中隨 SNR 上升」有多少是噪音、多少是做過一次，這份資料分不開。
- 瀏覽器把 64 位元的噪音種子存成浮點數，原始檔裡的種子被四捨五入；轉檔時改從 `online/snr_pilot/conditions.json` 依 row 取回精確值
  （`online/pavlovia_to_perception_csv.py`，本次修正；同時補上原本沒填的 `count` 欄）。

## 3. 三把尺的排序力（量到的；`analyze/acoustic_scale_validate.py --participant WEB01`，216 題「不同」試，漏 47）

排序力 = 答對的題分數高於答錯的題的機率，0.5 = 排不出來。

| 尺 | WEB01 [95% 區間] | yyc1116 [95% 區間] |
|---|---|---|
| M&N d′（現在的尺） | .42 [.33, .52] | .56 [.48, .64] |
| 差幾個發音特徵 | .53 [.44, .60] | .63 [.55, .70] |
| 頻譜圖差別（整對，12 位平均） | .86 [.81, .92] | .72 [.65, .80] |
| 頻譜圖差別（該題的說話者） | **.88 [.82, .94]** | .74 [.67, .81] |
| 樣板觀察者 d′ | .77 [.70, .84] | .69 [.61, .77] |

- 依頻譜圖差別四等分的命中率：WEB01 .35 / .84 / .96 / .98；yyc1116 .53 / .77 / .87 / .94（圖 32）。
- 邏輯迴歸 AIC：只放 SNR 200.7；SNR + M&N 201.2；SNR + 特徵數 201.6；SNR + 頻譜圖差別（該說話者）158.4。
  放進頻譜圖差別後 SNR 的係數從 +0.21 掉到 +0.05。
- 逐對命中率對 M&N d′ 的相關 r = -.13（`analyze/snr_pilot_pairs.py`；yyc1116 是 +.07）。

**這一項的性質**：頻譜圖差別的算法（視窗、頻帶、扣噪音底）在這份資料進來之前就定了（commit `eef8ae4`），
所以這是用新聽者做的檢驗，不是事後挑的。yyc1116 那一欄則是當初發展這把尺時用的資料。

## 4. 換算曲線（量到的；`analyze/acoustic_scale_listener_curve.py --participant WEB01 --compare yyc1116`，圖 31）

```
P(答不一樣 | x) = FA + (1 − FA − λ) / (1 + exp(−(x − x50)/s))        x = 頻譜圖差別 (dB)，FA = 該 SNR 的誤報
```

| | WEB01 | yyc1116 |
|---|---|---|
| 曲線中點 x50 | 1.98 dB [1.65, 2.29] | 2.51 dB [1.39, 3.08] |
| 到頂九成 x90 | 3.24 dB [2.70, 3.82] | 5.74 dB [2.14, 6.77] |
| 斜率尺度 s | 0.57 dB | 1.47 dB |
| 三個 SNR 各自一條 對 共用一條 | 概似比 8.00，df 6，p = .24 | 概似比 7.28，df 6，p = .30 |

- 兩位聽者的三個 SNR 都可以共用一條曲線（沒有證據要分開；不是證明相同）。
- 兩人的中點接近（區間重疊），WEB01 的曲線陡得多、到頂點早 2.5 dB。yyc1116 的數字與 scratchpad 版（2.36 / 5.21）略有出入，
  因為這支程式把 λ 限制在 0–0.3 並用逐題的說話者層級 x；差異在各自的區間內。

## 5. 先前的事後發現有沒有重現

- **「華語沒有的子音誤報較高」沒有重現**：WEB01 是 1/33 對 7/75（Fisher p = .43，方向相反）。yyc1116 當時是 17/35 對 18/72。
  WEB01 整體誤報太低（8/108），這個比較本來就沒有鑑別力；加上不知道他的母語，不能當成反證，也不能當成支持。
- **只差清濁的對子仍然幾乎沒測到**：f–v 3 題，命中 1。線上版的題目和 yyc1116 用的是不同的抽樣，但都沒有 b–p、g–k、s–z。

## 7. 限制

- 一位聽者、母語未知、線上、自備耳機（耳機檢查有過）。
- SNR 順序固定且題目重複（§1）。
- 「12 位說話者」實際上是三組近乎相同的錄音（T01–T06、T07–T09、T10–T12；另一份分析的發現，尚未寫進企劃書），
  所以「該題的說話者」層級的 x 有效的獨立來源比 12 少。
- 排序力高不代表絕對值可用：頻譜圖差別仍須每人換算（§4 兩人的斜率差 2.6 倍）。
