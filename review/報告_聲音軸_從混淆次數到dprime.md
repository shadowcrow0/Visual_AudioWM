# 研究報告：SFT 實驗的聲音維度，從「混淆次數」到 d′

2026-11-10。寫給 PI。英文版：`report_sound_axis_EN.md`。
所有數字都可以在 `review/` 的對應筆記與 `review/data/` 的檔案裡找到；本文只講脈絡與結論。

---

## 0. 一頁摘要

我們要用 SFT（Systems Factorial Technology）問：工作記憶裡的顏色與語音是平行、序列還是共啟動（coactive）處理。
SFT 需要每個維度各有「高顯著度 H」與「低顯著度 L」兩個水準，而且每位受試者要各自校準。
顏色維度有現成的知覺尺（ΔE），校準沒問題；**聲音維度沒有**，第一次 pilot（11-03）聲音在記憶負荷下全在猜測率。

我們查出原因之一是聲音軸本身：它是 Miller & Nicely (1955) 混淆次數的對數，不是知覺單位。
評估了七個替代方案後，選擇**對 M&N 的混淆矩陣做 GRT 擬合，用擬合出的 d′ 當聲音軸**。
結果：(1) 一張 240 個子音對的 d′ 表取代舊軸；(2) 擬合同時告訴我們哪些語音特徵在知覺上可分（voicing、nasality）、哪些不可分（place、manner），所以「差幾個特徵」不能當尺；(3) 第二次 pilot（11-10）在新軸上第一次量到聲音的 L。
還沒解決的：H 的目標（漂移差 8.0）兩個維度都到不了，目前只有一位受試者，規則先不改。

## 1. 實驗與它對刺激尺度的要求

```
   一個試驗：記 2 個顏色 + 2 個語音（CV 音節）→ 探測：一個顏色配一個語音 → 「兩個都出現過嗎？」Y/N
   SFT 需要的四格：顏色 {H, L} × 聲音 {H, L}，看 RT 分布的交互作用（SIC、MIC）
   H / L 怎麼定：每位受試者先做校準，用 LNRM（對數常態賽跑模型）擬合「漂移率 v 隨刺激差異 x 的變化」，
                 反解出漂移差 = 8.0（H）與 1.3（L）的 x
```

這套流程對 x 只有一個要求：**x 必須是一把單調、間距有意義的知覺尺**。顏色用 CIELAB 的 ΔE，1 單位 ≈ 剛好看得出。聲音要有一把對應的尺。

## 2. 我們先看到了什麼（pilot 2026-11-03）

```
   顏色：正確率隨 ΔE 乾淨上升；RT 平坦（~0.9 s）
   聲音：負荷下六個水準全部在猜測率（.40–.67，虛報 .22）
         同一人、無負荷的純知覺：最低層 .50、其餘 .83–1.00
```

三個可能原因：(a) 聲音軸排錯了；(b) 記憶負荷太重；(c) 受試者是華語母語，英語子音對比本來就弱。

## 3. 舊聲音軸的問題

舊軸 x = −log10(混淆次數 + 1)，次數來自 M&N 三個 SNR 的混淆表加總。問題：

1. **不是單位。** −1.6 沒有意義，無法跨研究比較，也無法和 ΔE 對照。
2. **把 voicing 對排到最遠端。** 噪音蓋不掉 voicing，所以 p–b、k–g 在噪音裡幾乎不混（次數 1），被當成「最不像」；但在記憶文獻裡 voicing 對常是最難的。
3. **不同類型的差異混在同一條軸。** 差 place 的對和差 manner 的對用同一個次數比，沒有理由相信它們同尺。

## 4. 問題陳述

給聲音維度一把**客觀、單調、以知覺為單位**的尺，讓 adaptive 校準能像在 ΔE 上一樣，找到每位受試者的 L（和 H）。

同時做的文獻查核（皆讀全文）：
- Schweppe, Grice & Rummer (2011)：序列回憶，只共享 manner 的組（pa ta ka）在任何呈現/回憶模式下都傷回憶，只共享 place 的組（da la za）只在口說回憶傷；作者**反對「數特徵」**。
- Roodenrys et al. (2025)：差一個構音特徵的子音在序列回憶中會干擾，視覺呈現也一樣；作者引 Wang & Bilger 說一半的對在聲學上不混 → 記憶裡的相似不全是聲學的。
- Cutler et al. (2004)：非母語（荷蘭）聽者整體 ≈ 母語的 80%，差距不隨噪音變；唯一清楚的 L1 效應是**詞尾 voicing**（荷語詞尾無濁音對比）。對華語聽者的對應預測是推論。
- 結論：M&N 的順序可當先驗，絕對值不行；記憶裡的距離最後要靠校準自己量。

## 6. 採用的做法：GRT 擬合 M&N（B 路線）

為什麼不直接擬 16×16：現成套件（mdsdt）只處理兩個維度；16 個子音是五條特徵軸。所以固定其餘特徵、切出特徵對的子設計。

```
   M&N 16×16 × 4 SNR
     │ 11 個特徵對子設計（voicing×place、voicing×manner、nasality×place、manner×place，各在不同脈絡）
     v
   mdsdt::fit.grt（等變異高斯、假設決策可分）：full / PS_x / PS_y / PI 模型，ΔAIC 比較
     │
     ├─ 可分性結論（−6 dB 為主）
     │     voicing、nasality：均值不隨另一軸移動 → 可分；voicing 與 place/manner 知覺獨立
     │     place：隨 voicing 變四倍以上（p–t 0.46 vs b–d 2.5）；manner：隨 voicing 變（k–ʃ 3.4 vs g–ʒ 1.1）
     │     → 刺激空間不是特徵軸的乘積，距離必須「按對查表」
     └─ 每對的 d′ = 該軸上的均值差；28 個單特徵對

   把 d′ 推廣到 120 對：對這 28 對，Luce 的 −ln η 與 GRT d′ 是過原點直線
       d′ = 0.911 · (−ln η)，Pearson .98
   → 120 對全部用 0.911·(−ln η)，寫成 stimuli/consonant_dprime.csv
```

對 GRT 讀者要說清楚的一點：我們**不是**說聲音維度知覺可分；擬合說的相反。把聲音壓成一個標量 x 是權宜，x 只需要單調。選擇性影響在 SFT 資料裡用 SIC 的檢定驗，不從尺假設。

## 7. 驗證：pilot 2026-11-10

**(a) 純知覺、固定 80 對**：命中 .81→.94 隨層級上升，但逐試分析答對與 d′ 無關（r = .06）；最像的 place 對（d′ 1.5）命中 .89 和 voicing 對一樣；錯誤集中在弱擦音。讀法：乾淨語音下整條尺都在天花板，這是預期，不是尺排錯；音檔音量查過與錯誤無關。

**(b) 在新軸上校準（有記憶負荷）**：

```
                     H              L         逐層正確率
   colour   ΔE 90（截）        39.4      ΔE 2–12 猜測率，25 以上全對
   audio    d′ 4.5（截，原 14.7） 1.57     .60–1.00；RT 從低層 1.7 s 降到高層 1.0 s
```

- **聲音第一次有斜坡**：正確率與 RT 都隨 d′ 變，LNRM 找到 L = 1.57（manner 對）。和 11-03 之間改了三樣（nochange 變體、按鍵收集修正、d′ 軸），分不出哪一樣是關鍵。
- **H 兩個維度都到不了 8.0**：漂移函數是二次式（α₂ < 0），有頂點；這位受試者的頂點在 8.0 以下，反解出的 H 來自 3% 有解的後驗抽樣外推，不穩。程式截到最高層。

## 9. 未決

1. **H 的規則**：維持 8.0 讓程式截到最高層（現況，只改訊息）；或寫死 H = 最高層只校 L。一位受試者不足以定，等 3–5 位。
2. **負荷**：聲音這次有斜坡，但只有一人一次；若下一位又是全猜，要考慮降負荷（研究者決定；目前目標數不改）。
3. **第二位聽者**（最好英語母語）跑同一張表，分開「人」與「尺」。
4. **說話者音量**：T10–T12 比其他人低 5–8 dB，下次改刺激時對齊。

## 10. 限制

M&N 是白噪音、/ɑ/、美式英語母語者；我們是乾淨語音、華語聽者。子矩陣條件化在子集內的反應。mdsdt 2×2 路徑固定 σ = 1。知覺距離 ≠ 記憶距離（Schweppe 同向、Roodenrys 反向）。一位受試者。
