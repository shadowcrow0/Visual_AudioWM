## 1. 五種指標

```
            矩陣 N (說 i, 聽成 j)
                 |
     +-----------+-----------+-----------------+
     v           v           v                 v
  特徵表      r_ab 混淆率   s_ab = (n_ab+n_ba)  Luce 選擇模型
  (Table XIX)  −ln r        /(n_aa+n_bb)      P(j|i)=b_j·η_ij/Σ_k b_k·η_ik
     |           |           |                 |
  hamming     confusion    古典 MDS           d = −ln η_ij
  weighted                 (Torgerson)
```

| 指標 | 公式 | 性質 |
|---|---|---|
| `hamming` | 差幾個特徵（0–5，place 不同算 1） | 描述性基線 |
| `weighted` | `Σ_f T_rel(f)·[f(a)≠f(b)]`，`T_rel = I(說;聽)/H(說)`，每個特徵把 16×16 塌成 2×2（place 3×3） | M&N 的「五條通道」 |
| `confusion` | `r_ab=(n_ab+n_ba)/(N_a+N_b)`，`d=−ln(r+ε)`，`ε=0.5/(N_a+N_b)`（半次計數；沒觀察到 → ≈6.9），−12/−6/0 dB 平均 | 描述性 |
| `mds` | −12/−6/0 dB 計數相加 → `s_ab` → `−ln s` → 古典 MDS，前 3 維歐氏距離 | Shepard 幾何圖像 |
| `luce` | 每個 SNR 最大概似估 120 個 η、15 個偏誤 b（每格 +0.5；起點為閉式解 `η≈√(p_ij p_ji/(p_ii p_jj))`），`d=−ln η`，−12/−6/0 dB 平均 | 知覺決策量測模型 |

只取 −12/−6/0 dB：−18 dB 全表近乎均勻（只傳 0.06 bit）；+6/+12 dB 240 個非對角格有 175/199 個為 0，距離全撞 ε 天花板。

## 4. 哪一個最接近認知理論

- **`luce`**（Luce 1963 / Shepard 1957）是知覺決策的**量測模型**：相似 η 與偏誤 b 分開估；Shepard (1987) `similarity = exp(−distance)` 使 −ln η 就是心理距離；Nosofsky (1986) GCM 用同一個 η 解釋分類與再認記憶。五者中只有它連得到記憶模型。
- `mds`：Shepard (1972) 對同一件事的幾何圖像（與 luce 0.94），但要選維數，且非最大概似。
- `weighted`：M&N 自己的「五條獨立通道」觀點，合理但只剩 27 個值。
- `hamming`、`confusion`：純描述；`confusion` 是未扣偏誤的 luce 近似（0.96）。

## 5. 建議：`luce`（−12/−6/0 dB 平均）

理由：理論地位最清楚、連續、每個子音 15 個 foil 跨 0.3–5.4、與現行軸 0.84（修正而非推翻）。`distance()`/`foil_nearest()` 預設即為 luce。

```
  4 級  0.29 | 3.04 | 4.09 | 4.68 | 5.44         每級 31/31/27/31 對，每子音每級 ≥ 1 ✔
  5 級  0.29 | 2.28 | 3.53 | 4.29 | 4.84 | 5.44  每級 24/23/23/26/24 對
        缺口：t 第 3 級（3.5–4.3）、z 第 5 級（>4.84）各無 partner
```

兩個缺口都只差一步（t 最近 ʃ 3.0 / ð 4.3；z 最遠 f、k 4.8），而 `foil_nearest` 本就貼到最近 foil 並回傳實際距離，5 級可用；要嚴格保證則合併第 4、5 級。對照：`weighted` 5 級（0.29|0.73|0.88|1.14|1.53|2.78）與 `confusion` 5 級（1.34|3.23|4.70|5.70|6.11|6.53）每子音每級皆 ≥ 1；6 級三者都有缺口。

## 6. 限制

1. **噪音 ≠ 記憶。** 這些距離量的是噪音裡的辨識；記憶裡是不是同一個結構，沒有人數值化比過：Wickelgren (1966) 說子音在 STM 以半獨立遺忘的特徵集合儲存，Klatt (1968) 重分析的記憶特徵裡有 voicing、沒有 place，Conrad (1964) 聽覺與回憶混淆相關（只到字母層級），沒有記憶裡特徵遺失的排序（見 `millerNicely1955_噪音混淆_逐SNR.md` §7–8）。`luce` 把只差 voicing 的對放在最遠端，當成要用純知覺測試和 WM 資料驗證的假設；若研究問題就是 voicing，改用 `weighted` 或自行校準——切換只是一個常數。
2. 聽者為英語母語者；非母語者的 η 會不同。
3. place 三值壓成同／不同：f-θ 與 p-k 都算一步。
4. 只有 CV + /ɑ/ 語境；`stimuli/` 是 12 位說話者的 /…3/ 音檔。
5. +6/+12 dB 的 η 幾乎只剩平滑常數，不要用。
