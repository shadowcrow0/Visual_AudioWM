# 決策脈絡 — 索引

這組文件記錄 AVWM 適應式 GRT 設計過程中**做過的判斷、依據、以及被推翻的假設**。
每個主題一個檔案,格式統一為:結論 → 依據 → **被推翻的假設**(誰說的、為什麼錯、
被什麼取代)。

寫下來的理由:這條決策鏈裡有多次反轉,而且好幾次是「先前的結論被實測或文獻推翻」。
只留最終結論的話,未來會不知道為什麼排除了某些選項,可能繞回已經走過的死路。

## 尚未定案

- **ΔE00 閾值跨色相圈是否重現** — A 組收完後檢驗;成立才進換色設計,見 [[決策脈絡_跨色相圈類推]]
- **聽覺維度最終選 VOT(合成)還是 SNR(自然)** — 證據目前傾向 SNR,見 [[決策脈絡_聽覺維度]]
- **子音配對** — /b/–/p/ vs /d/–/t/ vs /g/–/k/,待 [[consonant-pair-choice]]
- **試次數** — 目前每刺激 96 次;Silbert (2012) 用 200 次
- **WEB01（線上 SNR pilot，新聽者）** — 聲學尺第一次用新資料檢驗:英語母語者;排序力 .88,M&N d′ .42——表對母語者在我們的噪音下也排不出來(單人)。[[pilot_2026-11-24_WEB01_snr_pilot]]
- **CAL01（線上校準前測，+6 dB 一場）** — 第二位英語母語者:聲學尺 .89、M&N d′ .57;只差清濁的 42 題命中 .81(b–p、g–k 各 3/6),站在聲學尺這邊;+6 dB 對他偏簡單,L 端材料少。(單人)[[pilot_2026-11-26_CAL01_calib_pilot]]
- **現在的聲音尺 對 企劃書做法的評估** — 逐面向優缺點、C1 / C2 / C5 試算、說話者只有三組與母音不是 /ɑ/ 的核對、分階段走法;不做決定。[[evaluation_2026-11-24_current_vs_proposed_sound_scale]]
- **聲學尺的文獻先例** — 有相近先例(glimpsing、聽覺模型 + 樣板比對),「無先例」要收回;但可聽度類模型會低估清濁,與聲學尺把清濁對排最難相反。只到摘要層級。[[literature_2026-11-24_acoustic_distance_and_consonant_confusion]]
- **聲音難度尺** — 現在的 M&N d′ 表只對英語母語者、白噪音成立;提案與待決事項見 [[proposal_2026-11-24_language_independent_sound_scale]] §11
