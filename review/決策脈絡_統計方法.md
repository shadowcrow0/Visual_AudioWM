# 決策脈絡 — 目標正確率、intrusion 污染、效果稀釋

## 1. 目標正確率:`overallAccuracy = 0.64`

使用者的判準是 **GRT 聯合正確率至少 70% 才有意義**。因為 AGRT 的
`overallAccuracy` 參數有雙重開根號(見 [[決策脈絡_AGRT模型假設]]):

```
overallAccuracy | 單維   聯合   離 70% 底線
    0.5625      | 0.866  0.750   +0.050   ← 太緊,受試者間變異一晃就掉出去
    0.6400      | 0.894  0.800   +0.100   ← 採用
    0.7000      | 0.915  0.837   +0.137
```

配套:**受試者 valid 正確率 < 70% 就排除或重跑適應。**

## 2. 適應階段只跑 valid trial

三種策略在目標 75% 下的落點(r = invalid/valid 的知覺敏感度比,π = intrusion 率):

```
  r    pi  | A:只跑valid       B:50/50混合        C:只跑invalid
           | valid  invalid    valid  invalid     valid  invalid
 0.9   20% | 75.0%   56.5%    85.2%   64.8%     96.1%   75.0%
 0.9   40% | 75.0%   42.4%    94.8%   55.2%       —— 無解 ——
 0.7   40% | 75.0%   36.6%    97.2%   52.8%       —— 無解 ——
```

**天花板比地板危險。** 目標 75% 離地板(四選一機率水準 25%)有 50 個百分點,
離天花板只有 15 個。而 GRT 靠混淆矩陣的**非對角線**估參數 —— valid 到 95% 表示
12 個非對角格總共分到 5% 的試次,每格不到 5 次,參數估不動。

invalid 掉到 37% 則相反:**錯誤多得是**,而 invalid 條件要的本來就不是正確率,
是**錯誤的去向**。

(策略 C 在 π>25% 時無解:invalid 的上限是 1−π,刺激再簡單也到不了 75%。)

## 3. intrusion 會污染 GRT —— 而且相對比較救不了

**最重要的發現。** 模擬:真實 ρ=0(完全沒有知覺獨立性違反),只加入 intrusion:

```
真實 rho=0,intrusion 10%   →  Delta_SI = +0.01722
真實 rho=0.5,無 intrusion  →  Delta_SI = +0.01705    ← 一模一樣
```

**10% 的 intrusion 在知覺完全獨立的情況下,製造出跟 ρ=0.5 一模一樣的訊號。**

原因是**模型誤設**:GRT 的參數只有平均數、變異數、相關、決策界線,
**沒有一個參數叫「受試者報告了別的 item」**。那些多出來的 off-diagonal 質量
只能被最大概似推到相關參數上。

而且偏誤方向**不可預測** —— 真實 ρ=0.3 + intrusion 30% 反而是**低估**
(+0.022 vs 真值 +0.0315)。

**相對比較消不掉它,因為污染只在 invalid 一邊:**

```
valid   的 Delta_SI = 真實知覺效果
invalid 的 Delta_SI = 真實知覺效果 + intrusion 製造的假效果
────────────────────────────────────────────────
        差值        = 知覺變化 + intrusion       ← 混在一起
```

### ✅ 但平衡的 relation 讓它可以被拆開

因為 `relation` 隨機指派、不改變刺激,只決定 intrusion 落在哪一格:

$$\hat{\pi} = P(\text{報告 } t^r \mid \text{relation}=r) - P(\text{報告 } t^r \mid \text{relation}\neq r)$$

實測(每格 15 試次):**估到 ±0.004,而且完全不受真實 ρ 影響**(ρ=0 與 ρ=0.5 都準)。

還原:`M_grt[t, t^rel] = (M_obs[t, t^rel] - pi/3) / (1 - pi)`。
實測真實 ρ=0.3 + intrusion 30% → 觀察 +0.02206 → 還原 **+0.03152 = 真值**。

**這就是 relation 必須平衡的理由** — 見 [[決策脈絡_實驗設計]]。

### ⚠️ 扣掉 intrusion 之後還有一個坑

**不能直接比 Δ_SI**,它跟正確率有關:

```
valid   (rho=0.3, 80%)  ->  Delta_SI = +0.01006
invalid (rho=0.3, 55%)  ->  Delta_SI = +0.03152
```

**真實 ρ 一模一樣,Δ_SI 卻差三倍。** 比摘要統計量會得出「注意力讓違反變三倍」的假結論。

**要比的是擬合出來的模型參數(ρ、變異數比),不是 Δ_SI。**
擬合會把正確率差異吸收進平均分離度參數。

### ❌ 一個我搬錯的理由

我一度用「GRT 最低 70% 正確率」來論證 invalid 不能跑 GRT。
**那是搬錯理由。** 真正的問題跟正確率高低無關,是模型誤設。
而且實測顯示訊號在低正確率時**反而更強**(高正確率時混淆矩陣接近對角線,
相關性沒地方顯現):

```
聯合正確率 |  Delta_SI  | 相對 80% 的訊號強度
   80%     |  0.01705   |      100%
   45%     |  0.06734   |      395%
```

## 4. SNR 路線會稀釋知覺交互作用

外加噪音的變異加在內在變異上把它淹掉。σ_tot² = σ_int² + σ_ext²,
若顏色讓內在 SD 變動 20%:

```
 無噪音時 be/pe 正確率 | 外加噪音佔總變異 f | 交互作用被稀釋到
        95.0%          |     42.4%       |    59.8%
        99.0%          |     71.2%       |    30.7%
        99.9%          |     83.7%       |    17.6%
```

**be/pe 在安靜下越容易,稀釋越嚴重。** 若安靜時 99% 正確,只剩三成效果量,
要偵測同樣大小的交互作用試次數約需 10 倍。

緩解:(a) 加一個無噪音 block 估出 f,報告時說明稀釋倍數;
(b) 目標正確率設高一點;(c) 若 pilot 顯示 f>0.8,考慮換更難的對比。

## 5. 分析流程

```
1. valid trials   → 直接擬合 GRT → rho_valid, sigma_valid
2. invalid trials → 先用平衡的 relation 估 pi
                  → 扣除 intrusion 還原矩陣
                  → 擬合 GRT → rho_invalid, sigma_invalid
3. 比較 rho_valid vs rho_invalid(比參數,不比 Delta_SI)
4. pi 本身也是結果 —— 依 relation 分組看 pi 在顏色/聲音向度上是否不同
```

**前提是 `cued_item` 和 `relation` 一定要記錄,且 relation 要真的平衡。**
