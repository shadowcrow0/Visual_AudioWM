# 為什麼「只差一個特徵」的子音最難分、「差五個」最好分 —— 機制（2026-11-10，子代理整理，M&N 全文已讀）

## 0. 十歲版

一個子音不是一顆珠子，是一排五個開關：有聲嗎？從鼻子出嗎？有摩擦嗎？拖得長嗎？在嘴巴哪裡發？耳朵不是整顆去認，是五個開關各自讀一次。p 和 b 只有一個開關不同，那個讀錯就混；s 和 m 五個都不同，要五個全讀錯才會混。

```
            有聲  鼻音  摩擦  長   位置
     p       0     0     0    0    前(0)
     b       1     0     0    0    前(0)     ← 和 p 差 1 格
     k       0     0     0    0    後(2)     ← 和 p 差 1 格
     s       0     0     1    1    中(1)
     m       1     1     0    0    前(0)     ← 和 s 差 5 格
```

## 1. 出處：Miller & Nicely (1955), *JASA* 27, 338–352

- 五個特徵的定義與指派：pp. 346–347、Table XIX (p. 347)。作者自承 place「is by all odds the most superficial and unsatisfactory of the five features」(p. 347)。
- 每個特徵在各 SNR 傳了多少資訊（Table XXI p. 349 相對值，Fig. 1 p. 348）：

```
    S/N(dB)   −18   −12    −6     0    +6   +12
    有聲       2%   52%   81%   95%   96%   97%
    鼻音       1%   49%   73%   91%  100%  100%
    摩擦       0%    7%   28%   62%   78%   85%
    時長       0%   11%   31%   60%   78%   88%
    位置       0%    4%   16%   37%   49%   71%
```

  「Voicing and nasality are discriminable at signal-to-noise ratios as poor as −12 db whereas the place of articulation is hard to distinguish at ratios less than 6 db, a difference of some 18 db in efficiency.」(p. 349)
- 五個近乎獨立的通道：「the impressive thing to us was that this cross talk was so small and that the features were perceived almost independently of one another.」(p. 348)；摘要：「as if five separate, simple channels were involved rather than a single complex channel」(p. 338)。
- 低 SNR 塌成五群：|ptk|, |fθsʃ|, |bdg|, |vðzʒ|, |mn| (p. 352)。

## 2. 機制

**步驟 1：獨立通道 ⇒ 混淆機率是乘積**（推導；M&N 沒寫這條式子，只說 cross talk 小）

```
     P(A 聽成 B) ≈ ∏ P(第 i 個不同的特徵錯成 B 的值) ,  i = 1…k
```

代入 Table XX 在 −6 dB 的實測（place 正確 ≈ .60，voicing ≈ .97）：

```
     p→b  只差有聲            ≈ .03            ≈ 3%
     p→t  只差位置（3 選 1）   ≈ .40 × ½        ≈ 20%
     p→d  差有聲 + 位置        ≈ .03 × .20      ≈ 0.6%
     s→m  差五個               ≈ 五個小數相乘    ≈ 0
```

對照 Table III（−6 dB）p 這一列：p→t 43、p→b 1、p→d 1（每列約 250）。方向與量級吻合。

**所以重點不是「差幾個」，是「差的是哪個」**：差弱通道（位置）就很難，差強通道（有聲）其實不難——p–b 在 −6 dB 幾乎不混，p–t、p–k 大混。「特徵距離」只是把各通道的錯誤率粗略加起來的摘要。

**步驟 2：為什麼位置是弱通道**

M&N 原文：濁塞音的位置線索「seems to be in the initial portion of the second formant of the vowel」；清塞音的 F2 轉折「occurs during the period of aspiration, before vocalization has begun, and is correspondingly much harder to hear」(p. 347)；高頻成分弱、最容易被噪音蓋住 (p. 350)。有聲是疊在噪音上的週期性線譜、鼻音有鼻腔共振且較長較強 (p. 346)：低頻、週期、持續，噪音蓋不掉。

```
     時間 →
     p:  [爆發 ~10ms][送氣噪音 ~50ms][母音.....]
          ^ 位置線索在這裡：短、弱、高頻、被送氣噪音包住
     b:  [爆發][母音 F2 轉折.........]
          有聲線索 = 整段週期性低頻，長而強
```

背景（未讀，僅書目）：F2 轉折 → Liberman, Delattre, Cooper & Gerstman (1954) *Psychol. Monogr.* 68(8)；爆發音起始頻譜 → Stevens & Blumstein (1978) *JASA* 64, 1358–1368。

**步驟 3：短期記憶**

Wickelgren (1966) *JASA* 39, 388–398（摘要層級）：子音在 STM 裡「not as a unit but as a set of distinctive features each of which may be forgotten at least semi-independently」。推導：延遲後痕跡是「缺了幾格的開關列」，只差一格的探測只要那一格恰好丟掉就能冒充。哪一格先掉、他的特徵集是否同 M&N，未核全文。

```
     編碼時  p = [0 0 0 0 前]
     延遲後      [0 0 0 0  ? ]     ← 某一格掉了
     探測 t  = [0 0 0 0 中]   → 與痕跡不衝突 → 誤接受
     探測 m  = [1 1 0 0 前]   → 兩格衝突      → 拒絕
```

**步驟 4：特徵計數在哪裡失效**

(i) 特徵不等權（上表），且權重會隨情境變（Wang & Bilger 1973：安靜時 voicing/nasality 的相對優勢下降）。
(ii) 位置是三值，不是二值。
(iii) Soli & Arabie (1979) *JASA* 66, 46–59 用連續聲學維度（F2 轉折、起始頻譜）解釋同一批矩陣，不需要離散特徵。M&N 自己也只說「as if」五個通道，並提醒「the inputs to the five channels are not independent」(p. 348)。

## 3. 對本實驗的意思

- 用「差幾個特徵」排聲音難易度，比現在的噪音次數軸合理，但更準的是**按通道強弱加權**：差 place 的對 = 難，差 voicing / nasality 的對 = 易，差 manner 居中。
- 這套權重是噪音裡量到的；記憶裡的權重要看 Wickelgren 1966 全文（Conrad 1964 說聽覺混淆和記憶混淆高度相關，所以可能差不多）。見 `millerNicely1955_噪音混淆_逐SNR.md` §7。
