# 聲音軸怎麼來的：給老闆講的五歲版（2026-11-10）

搭配：`review/子音距離_怎麼算.md`（算法）、`review/consonant_distance_how.md`（英文）、`stimuli/sound_pairs.csv`（固定的 80 對）、`review/millerNicely1955_噪音混淆_逐SNR.md` §7–8（證據等級）。

## 1. 講的順序

1. **子音是五個開關拼成的**（聲帶震不震、鼻子出不出氣、爆還是嘶、嘶多長、嘴巴哪裡擋）。Miller & Nicely (1955) 的分法。
2. **兩個子音像不像，要看「差哪幾個開關」，不是「差幾個」。** 差「嘴巴位置」幾乎聽不出來（p–k），差「聲帶」很好聽（p–b）。這是從 M&N 在噪音裡測 4000 次 × 6 種吵度的混淆表算出來的。
3. **之前的做法錯在哪**：把 M&N 表裡「很少混」的對（p–b、k–g）當成「很不像」，而且只收每個子音 6 個對手，真正差最多開關的對（s–m、f–n）根本沒用到。
4. **現在怎麼算距離**：用數學心理學標準的「相似選擇模型」（Luce 1963 / Shepard 1957）把混淆表拆成「兩個音有多像」和「受試者偏好答哪個」兩部分，只留前者，取 −log 當距離。這跟 Nosofsky 的分類／再認記憶模型用的是同一個量。
5. **刺激固定**：算一次，生成 80 對（5 個距離層級 × 16 個子音），說話者固定，寫成表，實驗只讀表。
6. **還沒證明的**：這個距離是母語者在噪音裡聽出來的；記憶裡、非母語者是不是同一個順序，要用自己的純知覺測試和 WM 資料驗證。

## 3. 如果是 GRT

GRT 用的不是 η，是 **d′**：兩團「知覺分布」的距離。

```
   Luce / Shepard（相似選擇模型）                 GRT（Ashby & Townsend 1986）
   ───────────────────────────────                ─────────────────────────────────────
   直接從混淆矩陣估一個數 η_ab = 「a 和 b 多像」     假設每個刺激在腦中是一團雲（常態分布）
   沒有說「像」是怎麼產生的                         混淆 = 兩團雲重疊 + 決策線畫在哪
   d = −ln η                                      距離 = 兩團雲中心的差 ÷ 雲的寬度 = d′

        a  ●────── d = −ln η ──────●  b              a  (  ●  )(  ●  )  b
                                                          ↑ 重疊面積就是混淆率
```

- Luce 的 η 是「量出來的數」，GRT 的 d′ 是「從表徵模型算出來的數」。Ashby & Perrin (1988, *Psychological Review*, 書目憑記憶未核) 證明雲是常態分布時兩者在很多情況下對得上——GRT 把「為什麼像」說清楚，η 沒有。
- GRT 多做一件事：**把一個刺激拆成幾個維度**，檢定各維度是否獨立（perceptual independence）、一個維度的判斷會不會受另一個影響（perceptual / decisional separability）。M&N 用資訊傳遞量說「幾乎獨立」，GRT 可以正式檢定。

```
   GRT 線（GRTv3_ada）    本來就在量 d′：顏色 × 聲音各兩個水準，看兩個維度分不分得開
   SFT 線（SFT_WM）        校準量的是「漂移差」（LNRM 的 z₂ − z₁），本質上也是 d′ 一類的「分布距離」
                           Luce 距離只用來「排序」哪些子音對放哪一層；真正的 H / L 靠校準量出來的漂移差
```

最一致的講法：**子音之間的距離用 d′ 定義**（GRT 的語言），M&N 的矩陣只是先猜哪些對 d′ 大、哪些小，省掉把 120 對全校一遍。

## 4. 「用 GRT 擬合 M&N 的矩陣」是在做什麼（五歲版）

**M&N 的矩陣**：一張 16×16「聽錯了幾次」的表，只有數字，沒有「為什麼」。

**GRT 的想法**：每個子音在腦袋裡不是一個點，是一團雲，有中心、有大小。

```
   腦袋裡的「聲帶」軸 ──────────────────────────→
          (   p 的雲   )(   b 的雲   )           兩團離得遠、重疊少 → 很少聽錯

   腦袋裡的「嘴巴位置」軸 ─────────────────────→
          (  p 的雲 ( t 的雲 ) k 的雲 )           三團擠在一起、重疊多 → 常聽錯
```

噪音越大，雲越胖，重疊越多，錯越多。

**擬合 = 反過來猜雲長什麼樣**：看到「聽錯幾次」，去找一組雲的位置和大小，讓雲重疊的面積剛好等於表裡的錯誤率。找到了就得到：

1. **每一對子音的 d′**：兩團雲中心隔多遠（以雲的寬度當尺）。GRT 語言裡的「距離」，和 GRT 線、SFT 線量的是同一種東西。
2. **五個開關是不是各自一條軸**：「聲帶」軸上 p 和 b 的雲在「位置」軸上位置一樣 → 兩個開關不互相干擾（perceptual separability）。M&N 只能說「看起來幾乎獨立」，GRT 算得出是或不是。
3. **錯誤是雲重疊造成的，還是人偏好答某個音**：GRT 把「雲」和「決策線畫在哪」分開。Luce 也分，但 GRT 多了雲的形狀。

做出來會是：每個特徵一個 d′、每個 SNR 一列，加一個獨立性檢定。可以說「在 0 dB，聲帶軸 d′ ≈ 3、位置軸 d′ ≈ 1，兩軸獨立」——比「voicing 傳了 95% 的資訊」更接近實驗在量的東西。

**為什麼現在沒做**：16 子音 × 5 特徵的完整 GRT 模型參數很多，一張 4000 次的矩陣撐得起簡化版（每特徵一軸、等變異），撐不起完整版；而且它回答的還是「噪音裡」的距離，不是記憶裡的。是漂亮的延伸，不是眼前的瓶頸。
